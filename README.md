# MPD Fullstack

Полноценный fullstack-проект для плагина **MPD** (Material Process Definition) на платформе **Teamcenter**.

## Структура проекта

```
MPDFULL/
├── /client     — клиентский JS-код
│                 Собирается и копируется в /server/resources/public
│                 для встраивания в плагин Teamcenter
└── /server     — серверная часть плагина Teamcenter
                  Устанавливается непосредственно на базу
```

## О проекте

Репозиторий объединяет клиентскую и серверную части в одном месте для **единой версионности**. Это позволяет синхронно отслеживать изменения обоих компонентов и избегать рассинхронизации между ними.

> **Примечание:** Предыдущая история клиентской части хранилась в GitLab (`devrep/gitlab/teamcenter/mpd`) и будет удалена. Полная версия также сохранена у Кирилла локально.

## Разработка

### Клиентская часть

1. Вносите изменения в папку `/client`
2. После сборки скопируйте результат в `/server/resources/public`

### Серверная часть

- Код плагина находится в папке `/server`
- Устанавливается на целевую базу Teamcenter
